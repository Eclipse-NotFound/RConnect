# RConnect 联机模组 —— 安装与使用教程

> RConnect 为《Fallout Equestria: Remains》添加联机功能：
> 玩家通过网络一起游玩——互相可见、实时同步位置与
> 姿态、可聊天、可一起打怪（伤害经宿主权威结算）。
>
> 当前安装版：**0.2.1-dev（M29）测试候选**，已于 2026-09-20 部署修复。
> 修正加入方敌人被遮罩隐藏、同名敌人合并、近处加入者索敌及普通地雷生成。双方都需重启游戏。
> 当前验证以游戏 1.02 的同机双人合作为主，多人、真实网络和其他版本仍待验证。
> 本次 60 项检查、验证边界及回滚位置见 [M29 修复与部署记录](knowledge/experiments/2026-09-20-m29-enemy-visibility-targeting.md)。
> 既有合作交互范围见 [M28 验证](knowledge/experiments/2026-09-10-m28-cooperation-validation.md)。

## 一、功能一览（当前版本）

- 一人开房当**宿主**，另一人**加入**（三人以上待验证）
- 玩家互相可见：小马幽灵（半透明 + 头顶名字标签）实时跟随移动，
  带 stay/walk/run/jump 姿态动画，**手持武器同步显示**
- 远程玩家血量显示在联机面板
- 聊天（面板内输入，双方收发）
- 房间探索迷雾（暗幕）按房主视角点亮，两侧看到一致的当前房间
- 战斗协作：你对敌人的伤害会上报到宿主权威结算，双方世界同步
- 世界同步：双方在同一地图/房间时，敌人状态由宿主每 200ms 广播，
  客户端镜像（敌人位置/血量/姿态一致）
- 换地图/死亡回城自动跟随（配置项，见「进阶配置」）
- **世界注入（房主权威）**：加入方无需准备与房主一致的存档，房间敌人
  由房主世界镜像（缺失敌人自动生成、多余敌人移除、状态 5Hz 同步）
- 意外断线自动重连（测试配置，见「进阶配置」）
- 默认启动链为游戏 1.02；1.03 / 1.04 的完整功能仍待验证

## 二、安装

### 2.1 一次性安装（本机已完成，无需操作）

模组已安装到：

```
游戏目录/mods/Rconnect/release/RConnectMod.swf
```

并且三份游戏文件（`pfe.swf`、`DLC/pfe.swf`、`DLC/pfeUI.swf`）已打上
RConnect 加载器补丁（与 Sandevistan / RealisticVision / MoreSkills&Weapons
的加载器共存）。**直接启动游戏即可。**

### 2.2 新电脑安装 / 游戏文件被覆盖后重装

以下情况需要重新执行补丁步骤：

- 换了新电脑/新游戏目录；
- Steam 验证游戏完整性还原了游戏文件；
- Sandevistan 的同步脚本覆盖了游戏文件（本机存在多模组协作环境）。

步骤：

1. 把整个 `mods/Rconnect/` 文件夹放入游戏目录的 `mods/` 下
   （目录名必须是 `Rconnect`）。
2. 给游戏文件打加载器补丁（需要 Python 与 ffdec 反编译工具）：

   ```bat
   cd /d "你的游戏目录"
   python mods\Rconnect\tools\patch_game_swfs.py
   ```

   脚本会自动备份原文件到 `mods/Rconnect/build/backup/`；
   已打过补丁的文件会跳过（幂等）。若提示找不到 ffdec，用
   `--ffdec 你的ffdec路径` 指定。
3. 启动游戏验证：主菜单右上角应出现半透明黑色联机面板
   （"RConnect v0.1.0 | 1.02 …"）。

## 三、联机使用

### 3.1 联机前的重要前提

**加入方不需要准备与房主一致的存档。** 联机世界由**房主的存档**权威决定：
加入方进入游戏后，会自动跟随房主所在的地图与房间，房间里的敌人会被
"世界注入"镜像成房主的世界（房主世界有的敌人生成、多出的移除、
状态实时同步）。

建议：**房主开自己的存档/新档**；加入方用任意存档进游戏后点 Join 即可。

### 3.2 面板操作

启动游戏后，右上角面板：

| 元素 | 说明 |
| --- | --- |
| 状态行 | 当前模式（offline / hosting / joining / connected）+ 版本 |
| `name` 输入框 | 你的昵称（对方头顶显示的名字） |
| `ip` 输入框 | 加入时填宿主的 IP 地址 |
| `port` 输入框 | 端口，默认 23456，双方必须一致 |
| `Host` 按钮 | 开房：本机成为宿主并监听端口 |
| `Join` 按钮 | 加入：连接 `ip:port` 上的宿主 |
| `Leave` 按钮 | 退出当前联机（房主也会关房） |
| 聊天框 + `Send` | 发送消息（回车也可发送） |
| **F10** | 显示 / 隐藏面板 |

### 3.3 典型流程（两人局域网 / 互联网）

**房主（宿主）：**
1. 启动游戏，进主菜单。
2. 面板 `name` 填昵称，`port` 保持 23456（如被占用可换，如 23457）。
3. 点 `Host` → 状态变为 `hosting (port 23456, peers 0)`。
4. 正常开新游戏进入世界。
5. 对方加入后，状态显示 `peers 1`，对方小马会出现在你世界里
   （半透明 + 名字标签）。

**加入方：**
1. 启动游戏，填昵称。
2. `ip` 填房主的 IP（局域网用房主局域网 IP；互联网用公网 IP/域名），
   `port` 与房主一致。
3. 点 `Join` → 状态 `joining` → `connected (id 1 of 房主名, remotes 1)`。
4. 开新游戏进入世界后，即可看到房主的小马；双方互相可见。

### 3.4 互联网联机的网络要求

- **房主**需要让外部能连到其 `port`：
  - 路由器上为房主的电脑设置**端口转发**（TCP 23456 → 房主局域网 IP）；
  - Windows 防火墙放行（首次点 Host 时如弹窗请允许；或手动添加入站规则
    TCP 23456）。
- 加入方不需要任何端口设置。

## 四、配置说明

### 4.1 配置文件位置

- 模组默认配置：`游戏目录/mods/Rconnect/release/config.txt`（JSON）。
- 你在面板里修改的昵称/IP/端口会保存到：
  `%APPDATA%\pfe\Local Store\Rconnect_config.txt`（每个玩家的个人配置）。

### 4.2 常用字段（普通玩家）

```json
{
  "nickname": "Pony",
  "hostIp": "127.0.0.1",
  "port": 23456,
  "tickMs": 50
}
```

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| nickname | 昵称（面板也可改） | Pony |
| hostIp | 默认填写的加入地址 | 127.0.0.1 |
| port | 端口（双方一致） | 23456 |
| tickMs | 状态发送间隔毫秒（一般不用改） | 50 |

### 4.3 进阶字段（当前为测试开关，普通玩家可不碰）

在个人配置（`%APPDATA%\pfe\Local Store\Rconnect_config.txt`）中可加：

| 字段 | 值 | 作用 |
| --- | --- | --- |
| autoFollow | "1" | 加入方自动跟随宿主换地图/死亡回城（**推荐联机时开启**） |
| worldInject | "1"（默认开） | 世界注入：加入方房间敌人镜像成房主的世界（房主权威） |
| autoRole | "host"/"join" | 启动后自动开房/自动加入（自动化测试用） |
| freezeAI | "1" | 客户端冻结被镜像敌人的本地 AI（消除位置抖动；敌人动画由宿主状态驱动） |
| autoGame / autoMove / autoTravel / autoTravelLand / autoDamage | "1" / land id | 自动化测试钩子（自动开新游戏/传送/伤害），**普通玩家不要开启** |
| autoGhostDmg / testGhostDmg / autoHeal | "1" / 数值 / "1" | 测试钩子：宿主定期伤害加入方化身（数值=单次伤害，设大值可测死亡流程）；加入方复活后自动治疗 |
| autoLoadSave | 槽位号 | 测试钩子：程序化加载存档槽位（等价菜单 Continue，内部先建世界骨架） |

示例（加入方，开启跟随）：

```json
{
  "nickname": "PlayerB",
  "hostIp": "192.168.1.10",
  "port": 23456,
  "tickMs": 50,
  "autoFollow": "1"
}
```

## 五、常见问题

**Q：面板不见了？**
按 F10 显示/隐藏。

**Q：Join 一直 joining / 显示 connect failed？**
1. 房主是否已点 Host（状态为 hosting）；
2. IP/端口是否填对、双方端口一致；
3. 防火墙/路由器端口转发（见 3.4）。

**Q：能看到对方但对方在乱动/瞬移？**
客户端本地 AI 与宿主权威位置在竞争（同步间隔内的抖动）。
可在个人配置开启 `"freezeAI":"1"`（敌人动画会改由宿主状态驱动，更稳定）。

**Q：双方互相看不到（位置完全对不上）？**
确认加入方已 `Join` 且状态为 `connected`；世界注入会把敌人镜像成房主的
世界，玩家幽灵则随房主位置同步。若刚进入游戏，等几秒让同步建立。

**Q：游戏打字时角色乱动 / 按 Shift 后按键失灵？**
游戏内按 Shift 会切换中文输入法导致键位失效（游戏本体问题）。
联机聊天框聚焦时会屏蔽打字键影响角色；输入法切换请按 Ctrl+Space 切回英文。

**Q：换地图后对方没跟过来？**
确认加入方开启 `"autoFollow":"1"`。

**Q：联机里死了会怎样？**
和单人一样走死亡回城/复活流程；复活后房主世界里的"你的化身"会自动恢复，
继续跟随房主（开启 `autoFollow` 时）。刚复活身体部件带伤会被禁止旅行，
治疗一下即可（和单人模式一致）。

**Q：游戏文件被 Steam 还原 / 同步覆盖后模组不加载了？**
重跑补丁脚本（见 2.2）。

**Q：只有一台电脑，怎么自己测试双人联机？**
双击 `mods\Rconnect\tools\second_player.bat` 打开第二窗口（Player2，独立
存档目录，不碰真实存档）。第一窗口正常启动游戏 → 按 F10 点 **Host**；
第二窗口按 F10 点 **Join**（IP 默认 127.0.0.1 不用改）→ 两个窗口都进
游戏后即可联机测试（关掉第二窗口即退出）。

**Q：想看运行日志？**
`%APPDATA%\pfe\Local Store\RConnect.log`（联机连接/同步记录）。

## 六、已知限制（0.1.0 开发版）

1. **房间结构以加入方本地为准**：世界注入把当前房间的**单位**（敌人+
   中立 NPC/动物/装饰）镜像成房主世界（缺失生成、多余移除、状态 5Hz
   同步）；**随机图（rnd，如马哈顿）的房间布局已做确定性同步**——参加过
   补丁的双方进入同一随机图会是同一套布局（每次新档同一套），走廊/墙/门
   一致；门/箱等瓦片级物体仍以双方本地为准。Boss 单位（如 alicorn）的
   远端镜像仍受限（构造依赖内部数据，保持房主权威）。
2. **战斗权威双向**：你打敌人 → 伤害上报房主权威结算；敌人打你 →
   房主世界里"你的化身"（活体幽灵）受击后回传、本地真实掉血（护甲照常
   减伤）。你攻击过的敌人会转头打你的化身；敌人对未受攻击的目标仍优先
   找房主玩家——想挨打就去打它。
3. **死亡/复活协调**：你被打死 → 本地走游戏原版死亡回城流程（房主世界里
   你的化身暂时"倒下"并停止挨打）→ 复活后回满身体状态即可继续跟随房主
   （注意：身体部件伤重时游戏禁止旅行，需要先治疗——和单人模式一致）。
4. **版本兼容**：默认启动链为 1.02；1.03/1.04 加载器补丁已装，但联机验证
   主要在 1.02 完成。
5. 断线自动重连目前仅测试配置（autoRole=join）启用；手动联机断线后重新点
   Join 即可。
