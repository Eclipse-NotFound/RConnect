====================================================
  RConnect 联机模组 v0.1.0 —— 安装与联机说明
  （Fallout Equestria: Remains）
====================================================

【一、安装（在一个干净的游戏文件夹里）】

1. 找到游戏文件夹：
   Steam 里右键 Remains → 管理 → 浏览本地文件。

2. 解压本压缩包，里面有两样东西：
   - 三个游戏文件（pfe.swf 和 DLC 文件夹里的两个）
   - 一个 mods 文件夹

3. 覆盖三个游戏文件（建议先各备份一份）：
   - pfe.swf            → 放进游戏文件夹（根目录）
   - DLC\pfe.swf        → 放进游戏文件夹的 DLC 文件夹里
   - DLC\pfeUI.swf      → 放进游戏文件夹的 DLC 文件夹里
   提示"是否覆盖"时选"是"。

4. 把 mods 文件夹整个复制进游戏文件夹
   （Windows 会自动合并，不会删掉你已有的文件）。

5. 启动游戏，按 F10 —— 看到 RConnect 面板就是安装成功了。

====================================================

【二、联机（一个人开房，其他人加入）】

开房的人（房主）：
  1. 按 F10 打开面板
  2. 名字随意；端口保持 23456 不用动
  3. 点 Host —— 状态显示 hosting 就是开房成功
  4. 把【你的 IP 地址】和【端口 23456】告诉朋友

其他人（加入方）：
  1. 按 F10 打开面板
  2. 在 IP 一栏输入房主的 IP（端口 23456 保持不动）
  3. 点 Join —— 状态显示 connected 就是连上了
  4. 进游戏（继续自己的存档或开新档都行）——
     会自动跟随房主，世界以房主为准

三个人以上也可以：一个房主 + 多个加入方。

【怎么知道自己的 IP？】

- 在同一个 WiFi（同一台路由器，比如面基、家里两台电脑）：
  按 Win+R → 输入 cmd → 回车 → 输入 ipconfig → 回车 →
  找到 "IPv4 地址"（一般是 192.168.x.x），把这个数字告诉朋友。

- 不在同一个网络（隔着网线、异地）：
  用搜索引擎搜"我的IP"得到公网 IP，并且要在路由器里设置
  "端口转发"：把外部的 23456 端口转到你这台电脑的 192.168.x.x
  的 23456 端口（路由器品牌不同，设置位置不同，可搜索
  "【路由器品牌】端口转发 教程"）。

- 电脑弹出防火墙提示时，勾选"允许"。

====================================================

【三、常见问题】

- 连不上（一直 joining / connect failed）：
  1. 房主是否点了 Host（状态应为 hosting）；
  2. IP 和端口是否一致；
  3. 防火墙是否放行、路由器端口转发是否设置。

- 面板不见了：按 F10。

- 联机里死了：和单人一样回城复活；复活后会自动继续跟随房主
  （刚复活身体带伤会被禁止旅行，治疗一下即可，和单人一样）。

- 想改默认昵称/端口等：编辑
  %APPDATA%\pfe\Local Store\Rconnect_config.txt
  （详细参数见 mods\Rconnect\README.md 第 4 节）。

- 想看日志：%APPDATA%\pfe\Local Store\RConnect.log。
