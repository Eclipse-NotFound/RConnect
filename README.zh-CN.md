# RConnect 联机模组 —— 安装与使用教程

[English](README.md) · 简体中文

> RConnect 为《Fallout Equestria: Remains》添加联机功能：
> 玩家通过网络一起游玩——互相可见、实时同步位置与
> 姿态、可聊天、可一起打怪，也可在同一地图的普通房间分头行动。
>
> 当前安装候选：**0.2.19-dev**，2026-10-07。设置页新增30–100%窗口不透明度，分别保存；改善双向快速念力搬运，修正对方武器的原生翻转和开火显示。保留紧凑四页浮窗。最终16组1860项检查及正常加载通过，详见[部署记录](state/deployment-m47-2026-10-07.md)。真人鼠标/中文输入法仍需实测，背景门失控/死敌重现和密集卡顿仍待处理。
> 同机双人请先保存关闭两端，再使用 **[Start-Coop.bat](Start-Coop.bat)** 启动。它防止本次启动的游戏进程被后台节能降速，保留各自存档；可能增加耗电。密集战斗仍可能卡顿；本轮不声称普遍提高帧率。[操作说明](docs/local-coop.md)
> 2026-10-04 启动器修复：第二窗口不再被误当成自动测试而强开新档。首次启动继承旧第二角色的存档和设置，保留原档；以后启动自动打开原生读档列表，选择自己的角色继续。两个窗口使用同一游戏目录的当前模组。
> 同地图普通房间可分头探索、战斗和交互；无人房暂停，汇合和重返时保留敌人伤害、死亡、破墙、门箱与掉落进度。宿主发起全队换图，剧情与挑战区共同进出。**双方都需更新并完全重启游戏。**
> 保留对方动作和共享探索平滑、轻机枪伤害/护盾数字、双方不同护甲。蓝色 `S -数字` 表示护盾损耗，普通数字表示生命损伤。
> 保留 [M35炮塔修复](knowledge/experiments/2026-09-24-m35-turrets.md)、敌人开火、旋翼机死亡和破墙后显示。房间保留范围是当前地图、本次联机；关闭游戏后沿用原版保存，不新增随机房完整战斗存档。
> 当前验证以游戏1.02同机双人合作为主，稳定重连、多人、真实网络和其他版本仍待验证。
> 既有合作交互范围见 [M28 验证](knowledge/experiments/2026-09-10-m28-cooperation-validation.md)。

## 一、功能一览（当前版本）

- 双方可实际托举和投掷符合原版条件的敌人，沿用耗魔、重量和挣脱规则；换房交接前松手，断开时清理远端抓持
- 浮窗“设置”页的“菜单同步暂停”和“SATS同步暂停”：默认关、宿主设置；开启后任意一方触发全队暂停（含分房），双方都关闭后恢复，期间可操作菜单和SATS排队。暂停提示不随F10隐藏

- 一人开房当**宿主**，另一人**加入**（三人以上待验证）
- 玩家互相可见：小马幽灵（半透明 + 头顶名字标签）实时跟随移动，
  带 stay/walk/run/jump 姿态动画，**手持武器同步显示**
- 远程玩家血量显示在联机面板
- 敌人与队友位置在更新之间连续推进；隐身斑马／天角兽保留原生淡影和锁定限制
- 聊天（面板内输入，双方收发）
- 双方开火与弹道、天角兽闪电及护盾状态显示
- 地面掉落一份、先拾取者获得；双方开柜后都能看见并实际拾取
- 经验点一人激活双方奖励；存档点共享解锁，各自保存角色
- 浮窗“队友”页的“跟随队友”开关默认关闭；开启后随队友离开共同的普通房间
- 原生本地地图以青色菱形和名字显示队友位置，分房也可查看；标记随地图拖动和缩放
- F10“传送到队友身边”支持同地图普通房间，交接完成后落在队友附近可站立处；剧情、挑战和跨地图仍由宿主带队
- 双向共享同房间探索记录，各端独立控制接收，关闭后保留已收到区域；RV 按本机视野设置显示
- 普通房间可分头：所在玩家推进该房战斗；同房时由宿主统一结算，加入侧上报伤害
- 空房暂停并保留进度；有人进入或双方汇合时先交接房间，再继续战斗
- 世界同步：双方在同一地图/房间时，敌人状态由宿主每 200ms 广播，
  客户端镜像（位置在快照间平滑过渡，动画按游戏帧推进）
- 宿主发起共同换地图；加入侧地图按钮、返回卷轴与跨图出口会提示由宿主带队
- 剧情和挑战区共同进出，挑战波次由宿主运行；原版死亡恢复流程保留
- **世界注入（房主权威）**：加入方无需准备与房主一致的存档，房间敌人
  由房主世界镜像（缺失敌人自动生成、多余敌人移除、状态 5Hz 同步）
- 意外断线自动重连（测试配置，见「进阶配置」）
- 默认启动链为游戏 1.02；1.03 / 1.04 的完整功能仍待验证

## 二、安装

### 2.1 一次性安装（本机已完成，无需操作）

模组已安装到：

```
游戏目录/mods/Rconnect/release/RConnectMod.swf
```

并且三份游戏文件（`pfe.swf`、`DLC/pfe.swf`、`DLC/pfeUI.swf`）已打上
RConnect 加载器补丁（与 Sandevistan / RealisticVision / MoreSkills&Weapons
的加载器共存）。**直接启动游戏即可。**

### 2.2 新电脑安装 / 游戏文件被覆盖后重装

以下情况需要重新执行补丁步骤：

- 换了新电脑/新游戏目录；
- Steam 验证游戏完整性还原了游戏文件；
- Sandevistan 的同步脚本覆盖了游戏文件（本机存在多模组协作环境）。

步骤：

1. 把整个 `mods/Rconnect/` 文件夹放入游戏目录的 `mods/` 下
   （目录名必须是 `Rconnect`）。
2. 给游戏文件打加载器补丁（需要 Python 与 ffdec 反编译工具）：

   ```bat
   cd /d "你的游戏目录"
   python mods\Rconnect\tools\patch_game_swfs.py
   ```

   脚本会自动备份原文件到 `mods/Rconnect/build/backup/`；
   已打过补丁的文件会跳过（幂等）。若提示找不到 ffdec，用
   `--ffdec 你的ffdec路径` 指定。
3. 完全重启游戏验证：默认左上游戏信息带下方出现短状态条。
   点击▼展开，进入“设置”页核对运行版本0.2.17-dev；若曾拖动，沿用已保存位置。

## 三、联机使用

### 3.1 联机前的重要前提

**加入方不需要准备与房主一致的存档。** 联机世界由**房主的存档**权威决定：
加入方首次进入后，会先与房主汇合。同地图普通房间随后可自由分头行动；
同房时接收宿主的敌人与场景状态，独房时运行本地战斗。汇合或换房时，
双方短暂停下完成交接，已造成的破坏和敌人伤害随房间保留。

建议：**房主开自己的存档/新档**；加入方用任意存档进游戏后点 Join 即可。

### 3.2 面板操作

启动游戏后，浮窗默认收为短状态条。点击▼展开；F10用于隐藏/恢复，保留原开合状态。

| 元素 | 说明 |
| --- | --- |
| 状态条 | 连接状态、聊天/未读数、展开或收起；新消息不抢焦点 |
| 连接页 | 昵称、宿主地址、端口（默认23456）；创建房间/加入/离开。错误显示在本页，输入保留 |
| 队友页 | 队友名字与生命、共享探索、跟随队友、传送到队友身边；未就绪时说明原因 |
| 聊天页 | 输入、发送与最近50条记录；Ctrl+Enter在普通游玩时打开聊天，输入框Enter发送 |
| 设置页 | 菜单/SATS同步暂停与版本；联机时由宿主设置，加入侧只读 |
| 标题、停靠、说明 | 拖动标题移动；“停靠”依次切换四角；“说明”显示操作帮助 |
| 滚轮、Esc | 当前页长内容内部滚动；Esc收起并释放聊天焦点 |
| **F10** | 显示 / 隐藏面板 |

连接成功后自动收起。原版菜单、对话和SATS优先使用自己的按键；聊天输入框外的Enter仍是原版全屏键。标题位置和开合按玩家分别记忆；窗口缩小后限制在可见范围。真人中文输入法与实体鼠标仍需实测。

### 3.3 典型流程（两人局域网 / 互联网）

**房主（宿主）：**
1. 启动游戏，进主菜单。
2. 点击▼展开“连接”页，填昵称，端口保持23456（如被占用可换，如23457）。
3. 点“创建房间”（英文Host）→ 状态条显示宿主等待队友。
4. 正常开新游戏进入世界。
5. 对方加入后，状态条显示双方已联机，对方小马会出现在你世界里
   （半透明 + 名字标签）。

**加入方：**
1. 启动游戏，点击▼展开“连接”页，填昵称。
2. `ip` 填房主的 IP（局域网用房主局域网 IP；互联网用公网 IP/域名），
   `port` 与房主一致。
3. 点“加入”（英文Join）→ 显示连接中，成功后状态条显示已加入并自动收起。
4. 开新游戏进入世界后，即可看到房主的小马；双方互相可见。

### 3.4 互联网联机的网络要求

- **房主**需要让外部能连到其 `port`：
  - 路由器上为房主的电脑设置**端口转发**（TCP 23456 → 房主局域网 IP）；
  - Windows 防火墙放行（首次点 Host 时如弹窗请允许；或手动添加入站规则
    TCP 23456）。
- 加入方不需要任何端口设置。

## 四、配置说明

### 4.1 配置文件位置

- 模组默认配置：`游戏目录/mods/Rconnect/release/config.txt`（JSON）。
- 你在面板里修改的昵称/IP/端口会保存到：
  `%APPDATA%\pfe\Local Store\Rconnect_config.txt`（每个玩家的个人配置）。

### 4.2 常用字段（普通玩家）

```json
{
  "nickname": "Pony",
  "hostIp": "127.0.0.1",
  "port": 23456,
  "tickMs": 50
}
```

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| nickname | 昵称（面板也可改） | Pony |
| hostIp | 默认填写的加入地址 | 127.0.0.1 |
| port | 端口（双方一致） | 23456 |
| tickMs | 状态发送间隔毫秒（一般不用改） | 50 |

### 4.3 进阶字段（当前为测试开关，普通玩家可不碰）

在个人配置（`%APPDATA%\pfe\Local Store\Rconnect_config.txt`）中可加：

| 字段 | 值 | 作用 |
| --- | --- | --- |
| autoFollow | "1" | 保留共同旅行兼容设置；房间协议建立后，普通房间无需关闭此项即可分头 |
| worldInject | "1"（默认开） | 世界注入：加入方房间敌人镜像成房主的世界（房主权威） |
| autoRole | "host"/"join" | 启动后自动开房/自动加入（自动化测试用） |
| freezeAI | "1" | 同房镜像冻结本地敌人AI；独房战斗与交接时由房间协议自动切换 |
| autoGame / autoMove / autoTravel / autoTravelLand / autoDamage | "1" / land id | 自动化测试钩子（自动开新游戏/传送/伤害），**普通玩家不要开启** |
| autoGhostDmg / testGhostDmg / autoHeal | "1" / 数值 / "1" | 测试钩子：宿主定期伤害加入方化身（数值=单次伤害，设大值可测死亡流程）；加入方复活后自动治疗 |
| autoLoadSave | 槽位号 | 测试钩子：程序化加载存档槽位（等价菜单 Continue，内部先建世界骨架） |

示例（加入方，开启跟随）：

```json
{
  "nickname": "PlayerB",
  "hostIp": "192.168.1.10",
  "port": 23456,
  "tickMs": 50,
  "autoFollow": "1"
}
```

## 五、常见问题

**Q：面板不见了？**
按 F10 显示/隐藏。

**Q：Join 一直 joining / 显示 connect failed？**
1. 房主是否已点 Host（状态为 hosting）；
2. IP/端口是否填对、双方端口一致；
3. 防火墙/路由器端口转发（见 3.4）。

**Q：能看到对方但对方在乱动/瞬移？**
当前版本由房间协议自动管理原生战斗和镜像动画。双方先核对版本并完全重启；
仍出现时可从运行日志定位具体地图、房间与交接状态。

**Q：双方互相看不到（位置完全对不上）？**
确认加入方已 `Join` 且状态为 `connected`；世界注入会把敌人镜像成房主的
世界，玩家幽灵则随房主位置同步。若刚进入游戏，等几秒让同步建立。

**Q：游戏打字时角色乱动 / 按 Shift 后按键失灵？**
聊天框聚焦时会屏蔽打字键影响角色，松键时释放原版动作状态。
真人中文输入法仍需实测；遇到原版输入法卡键时，可用Ctrl+Space切回英文。

**Q：换地图后对方没跟过来？**
双方须使用相同候选版并完全重启。普通房间分头后不会自动拉回；整张地图与挑战区由宿主带队切换。

**Q：联机里死了会怎样？**
和单人一样走死亡回城/复活流程；复活后房主世界里的"你的化身"会自动恢复，
继续跟随房主（开启 `autoFollow` 时）。刚复活身体部件带伤会被禁止旅行，
治疗一下即可（和单人模式一致）。

**Q：游戏文件被 Steam 还原 / 同步覆盖后模组不加载了？**
重跑补丁脚本（见 2.2）。

**Q：只有一台电脑，怎么自己测试双人联机？**
保存关闭已有窗口，双击 `mods\Rconnect\Start-Coop.bat` 打开两端。
分别进入角色后，点击▼展开“连接”页；第一窗口点“创建房间”（Host），第二窗口用地址127.0.0.1和相同端口点“加入”（Join）。
第二窗口沿用独立pfe2角色，没有存档时新建角色；启动器不复制覆盖存档。
只开第二窗口仍可用 `tools\second_player.bat`，详见[同机启动说明](docs/local-coop.md)。

**Q：想看运行日志？**
`%APPDATA%\pfe\Local Store\RConnect.log`（联机连接/同步记录）。

## 六、已知限制（0.2.17-dev）

1. 验证范围为游戏1.02、同机双人；稳定重连、三人以上、真实网络和其他版本未纳入本轮。
2. 分头行动限同地图普通房间。整张地图及剧情/挑战区域由宿主带队，加入侧出口会显示提示；任务、背包与交易没有新增同步规则。
3. 空房进度保留限当前地图、本次联机。关闭游戏后的保存沿用原版，不额外保存随机房完整战斗状态。
4. 双方需要相同游戏和地图资源。房间尺寸不一致时交接会停止并提示，不能把两套不同布局强行合并。
5. 已覆盖原生炮塔、常见敌人、开火/机械死亡、破墙与合作伤害；特殊Boss、第三方敌人和所有武器/状态效果组合未穷举。
6. 死亡恢复沿用原版，身体部件重伤仍可能禁止旅行；所有死亡、过门和失联同时发生的时序尚未穷举。
7. 防止后台节能降速需要通过Start-Coop启动；SWF不能单独设置Windows进程策略。密集敌人的原生绘制和其他模组开销仍在，不承诺所有机器或场景满帧。未穷举全部武器弹道类型。
