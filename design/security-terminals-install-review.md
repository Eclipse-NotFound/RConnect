# 安保终端开关：安装内容预览

## 玩家看到的变化

RConnect浮窗的“设置”页增加“安保终端”一项，由宿主选择，加入侧显示当前选择：

- **共享破解（默认）**：一人破解后，该终端控制的炮塔不攻击双方。
- **分别破解**：每人单独破解；尚未破解的人仍会被炮塔发现、攻击，也可以正常反击炮塔。

切换设置保留已取得的安全权限，只影响之后的破解。个人破解次数、失败和锁定状态分别保留；设置仍在原有可滚动面板内，不增加浮窗高度。

## 安装和回退边界

安装前再核对当前文件，任何并行更新都必须先合并。备份计划放入新的 `build/m52/security-install-20261019-01`，保存两份安装前文件与校验清单；同名目录存在则中止。安装后通过原加载器进行独立双人启动检查，失败恢复两份备份。游戏需要重启才能使用新版本，不会替用户关闭游戏。

这个候选基于现用fix39，尚未包含另行验证的Q传送、投掷物抓取、房间加载候选或RV/WB优化；后续统一合并必须重新验证，不能直接覆盖。本次不声称已解决密集场景卡顿或旧首次掉落延迟。权限记忆限本次联机及地图轮次，不新增跨重启随机地图战斗存档。

本体安装需要本轮明确授权，依据工作区`GOVERNANCE.md`第6节及[发布门禁第4项](../../../.agents/skills/remains-release-gate/SKILL.md)：“涉及游戏文件（SWF/描述符）的改动必须有用户本轮明确授权”。当前只完成隔离候选；待批准的具体动作是备份并替换上表两份文件，之后冒烟，失败回退。
