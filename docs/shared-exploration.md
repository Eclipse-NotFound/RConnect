# 共享探索（当前 0.2.5-dev）

双方进入同一地图与房间后，会双向分享探索过的区域。原版遵循原有明暗机制；安装新版 RealisticVision 时，由它按本机模式、记忆亮度等设置显示。

0.2.5 起，有新变化时最快每 100ms 更新一次，并减少重复发送的地图内容；完整房间仍每三秒补齐。双方需要同时更新到 0.2.5，不能混用旧版。实际更新速度受游戏运行速度与连接状况影响。

在 **F10 联机面板 → 接收队友探索** 切换，也可在可用的模组设置页找到 **RConnect 联机**。默认开启；每个人独立控制自己的接收。

- 关闭后停止接收新的探索，已经收到的区域继续保留。
- 自己关闭不会妨碍队友接收自己的探索。
- 再打开后通常在三秒内补齐当前房间记录。
- 断开后保留当前世界中已取得的记录；读档、新游戏或游戏重新生成房间时，随原有房间/世界生命周期重置。没有另建永久探索存档。
- 只共享探索显示，不新增瞬移落点或鼠标交互权限，也不把历史探索当作 RV 当前视线。既有联机敌人报点规则保留。

RConnect **不要求安装 RV**。RV 没有安装，或处于关闭/vanilla/基地透传模式时，使用原版显示。RV current/classic 的完整共享效果需配套带探索接口的 v0.30.0。旧 RV 没有此接口，其自建雾层无法保证显示新增共享区域。

配置键 `sharedExploration`：`"1"` 开启、`"0"` 关闭；开关会保存到本端已有 RConnect 用户配置，不改变对方的配置。原版会重新变暗的特殊房间继续遵循其规则。
