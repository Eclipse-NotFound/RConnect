# 同机双人启动

保存并关闭原来的游戏窗口，然后双击模组目录中的 **Start-Coop.bat**。它会打开主窗口和第二窗口。分别载入角色后，点击短状态条的▼展开“连接”页：主窗口点“创建房间”（Host），第二窗口填写同一端口、地址127.0.0.1，再点“加入”（Join）。F10用于隐藏/恢复浮窗。

主窗口沿用原来的角色；第二窗口保留自己的角色，启动后选择已有存档。0.2.15-dev起自动打开原生读档列表；若停在主菜单，点击“载入游戏”即可。第一次没有角色时，可以取消读档、新建角色。

2026-10-04 的启动器修复解决了旧第二窗口被技能武器模组误当成自动测试、主动新建角色的问题。第一次使用修复后的入口时，须先保存并关闭旧第二窗口；启动器会把 `pfe2` 的存档和设置复制到新的独立角色目录 `%APPDATA%\pfe-modsettings-rconnect-player2\Local Store`。原来的 `%APPDATA%\pfe2\Local Store` 保留，主角色不参与复制。以后始终使用新目录，不重复覆盖；双方仍在游戏内分别保存。历史日志不复制，旧测试用自动开档/自动操作配置被关闭，正常玩法设置保留。

第二窗口和主窗口都直接加载当前游戏目录的模组，不维护另一套旧版本。启动器会显示加载目录及RConnect文件校验码；游戏内展开“设置”页查看实际运行版本。日志为追加格式，判断版本应看最后一次 `initialized`，不要看文件头的旧记录。

这个入口会让它启动的游戏进程在切到后台后保持运行速度。测试中，Windows 的后台节能策略曾使同一密集场景的帧数减半；此设置只作用于本次游戏进程，退出后结束，可能增加耗电。普通游戏入口仍可用，但不会获得这项后台运行设置。

如果对应游戏已经开着，启动器会提示先关闭；请保存退出后重试。同机合作使用本包附带的 Start-Coop.bat；异地两台电脑各自正常启动游戏，不需要双开。

“队友”页的“跟随队友”默认关闭。开启后，队友离开你们共同所在的普通房间时自动跟随；关闭后继续自由分头。已分开时开启不会立即把人拉回。整张地图和剧情／挑战仍由宿主带队。

地面物品只有一份，先拾取者获得；经验点由一人激活后双方获得奖励；存档点共同解锁，双方分别保存自己的角色。房间进度仍只保留在当前地图、本次联机内。

## 可选全队暂停

0.2.16-dev起，宿主可分别开启“菜单同步暂停”和“SATS同步暂停”；0.2.17-dev将它们放入浮窗“设置”页。默认关闭，设定会保存；加入侧显示宿主的设置。全队暂停提示不随F10隐藏。

开启后，任意一方打开相应界面，双方的战斗一起暂停，分房也生效。菜单包括原版会暂停的设置、背包、地图等；F10本身不触发。双方都关闭相关界面后才恢复。暂停期间可聊天、操作菜单及在SATS里排队，排好的攻击等待全队恢复后执行。关闭同步开关时，本机菜单仍按原版暂停。

加入侧也可实际托举/投掷符合原版条件的敌人；保留魔力、重量、视线和挣脱限制。全队暂停时保持抓持、停止耗魔和挣脱计时，恢复后继续；房间交接前松手，断开时清理远端抓持。

0.2.20-dev修正共享SATS的显示衔接：暂停期间收齐最后到达的敌人位置，选敌图层一同对齐，恢复后不再补跳旧位置。念力物品的移动曲线与开箱掉落显示也作了平滑处理；双方保存后完全重启才能生效。

## 窗口不透明度

0.2.19-dev起，展开浮窗的“设置”页，用减/增调整窗口不透明度，范围30–100%，每次10%。默认100%。这是各角色自己的显示设置，分别保存；全队暂停提示始终完全不透明。控件获得焦点时也可用方向键调整，Home到30%、End到100%。
