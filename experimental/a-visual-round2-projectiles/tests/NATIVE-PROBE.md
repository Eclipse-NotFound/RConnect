# 原生特殊弹最终绘制采样

状态：只准备源码，尚未编译或运行。母会话负责与当前准确候选集成、登记并启动隔离实例。没有修改产品、共享入口、正式存档或其它模组。

## 本轮边界

`../src` 的旧候选保留为历史调查证据。其中“迟到补播”已被母会话撤回：独立时间偏移可能让弹道与移动枪口、墙面火花前后顺序不一致。本探针应测试母会话的**原时轴、已确认样本间插值**整合候选，不把旧候选当作选定实现。

`NativeProjectileProbe.as` 复用 `experimental/a-stutter-investigation/RConnectMod.as` 的隔离加载器和 `stutter-probe` 控制消息。将本文件编译为独立 `EffectsDriver.swf`，产品作为单独的 `tests/RConnectProduction.swf` 加载。保持原加载器静音、独立应用 ID、端口与存储规则；本文件不创建编排进程。

四段实际动作，共约 31 秒，另加启动准备时间：

| 段 | 原生动作 | 目的 |
| --- | --- | --- |
| both-lmg | 两个本机玩家以原生控制持续射击轻机枪 | 普通弹与双向显示基线 |
| both-cflamer | 双方持续发射原生火焰武器 | 火焰坐标、缩放、透明度、内部帧 |
| both-prism | 双方短按/松开原生半自动棱镜枪，缓慢小幅改变瞄准 | 六色光束长度、方向及末段随枪口变化 |
| enemy-lightning | 宿主创建一个原生天角兽，原生 Weapon.attack/step 发射 alilight | 宿主敌人到加入侧的闪电路径 |

每段最后 1.5 秒停止发射，观察真实终止。天角兽仅关闭自主战术，由驱动请求原生开火，不改 Bullet.step，不在加入侧生成或推动敌人。原生玩家的控制和武器逻辑负责前三段射击，驱动只提供开火输入、瞄准及夹具弹药。宿主和加入侧均等开场复活、控制恢复、房间就绪后才开始。

927208cf9e 暴露并修正了棱镜枪操作夹具：持续按住只产生一轮六色光束，每个原生弹只存活约三帧，不能称作持续光束。当前使用 750ms 周期中短按 100ms，其余时间松开，保持原生 auto/rapid 不变；验证改为双侧至少 9 次实际可见采样、可见样本跨越至少 2 秒，不以 Weapon.b 变化次数代替可见过程。正弦瞄准只通过原生玩家目标坐标进入武器逻辑，不设置弹丸位置。

## 输出与判断

沿用每个隔离实例存储内的 `stutter-result.json`。`completed` 只说明四段执行完成；`passed` 和 `checks` 才表示采样/开火/可见对象覆盖达标。显示缺失仍会保留后续采样，不提前退出并丢失其它武器证据。

- `rows`：每个最终 `RENDER` 的本机/对侧角色姿势、弹道实际显示坐标、旋转、缩放、透明度、原生 MovieClip 帧、激光子对象长度/帧。`native` 根据真实 Bullet.vis 身份标记，不按猜测位置区分。
- `sourceRows`：同一最终绘制时刻、仍在原生链中的实际 Bullet 物理坐标、速度、生命周期和视觉坐标。不要把 X/Y 与视觉坐标不同直接判为错误；原生光束末段会随枪口移动。
- `births` / `sourceEnds`：首次观察到的原生对象及脱链时刻、最终真实位置。`births.at` 是观察时间，不冒充构造函数的精确调用时间；原生视觉可能出生时尚不可见。
- `wire`：每个源/武器流/事件 ID 的收到时间、源时间、结束时间和更新次数；每个流前 12 个事件额外保留去重后的完整源样本及每次收到更新的边界。事件对象始终只读。其它事件仍计数，不改变产品发送内容。
- `wireSamples`、消息/字节/样本计数、真实帧间隔：用于解释观察结果。因为探针逐帧记录且只测少量武器，不能独立当作整侧性能基准。

核对顺序是源端最终绘制 → 消息中真实样本 → 收端最终绘制。源端已经不动的原生终末停留不得归为网络卡顿；在已有前后源样本之间出现阶跃，才对应本轮插值修正。真实墙面火花顺序和枪口必须与同一原时轴核对。本探针没有补时、预测、私自读写渲染游标或生成替代轨迹。

此小范围探针不覆盖暂停、射手死亡、换房、原生命中伤害和全部武器动画；不得凭它声明这些功能已回归通过。
