# A 第二轮弹道调查与已撤回的补播实验

最终采纳状态：根候选 `a-visual-round2` 只采用已收轨迹内的 `sample` 插值；本目录 `time` 迟到补播会与枪口和墙面火花错位，已撤回，未部署。实际部署EB6D/animfix3及原生对照见 `state/a-visual-feedback-repair-2026-10-28.md`。下文保留初始调查设计，不能把这里的整套覆盖用于生产；组件正式证据是根目录35项 `ProjectileSampleChecks`，不是本目录旧回放源码。

基线：正式 `F14A / 0.2.24-animfix2`，准确全源 `build/m52/a-stutter-repair-02/src`。

## 定位

- `ProjectileVisuals.tickBeam` 原先将闪电、火焰、激光，以及缩放发生变化的弹丸全部排除位置插值。即使已经收到前后帧，也保持前一坐标，随后跳到下一坐标。
- 同函数先按角色共享游标判断 `time >= end`；若短命弹丸的首个消息迟到，角色游标已越过结束时刻，该弹在首次绘制前便直接删除。它不是正常的原生终末停留。
- F14A 的正常原生终末停留没有修改，不补末端点、不向前预测。07da 轻机枪/速射等离子枪有效段的连续飞行完全重复坐标计数为 0，但双方本机/远端均有长帧及不等步长；这些旧日志不能证明全部卡顿消失。

## 窄改动

只替换 `ProjectileVisuals` 并新增纯计算类 `ProjectilePlayback`。不改 `Session`、`RemoteMotion`、`UnitPresentation`、伤害、消息频率、收集内容或事件去重。

1. 所有类型已确认前后样本的位移、同向缩放、透明度及激光长度连续插值；原生 MovieClip 帧仍离散播放，翻转保持原跳变，不在样本外预测。每颗弹复用临时结果对象。
2. 仅从未绘制、但已经完整收到结束时间的迟到弹丸，按原可见起点至结束的时长补播一次。同一武器同时迟到的多发按源时间间隔补播；已绘制或已去重删除的弹不重播。
3. 迟到补播使用自己的时间偏移；共享暂停时偏移按暂停时长延后，射手死亡后不依赖其已退休游标。爆炸仍由原来的 `exploded` 标记保证一次，且先确定补播时间再判爆炸。

## 验证入口与边界

`tests/ProjectilePlaybackReplay.as` 是独立 AIR 组件回放入口：以本目录 `src` 编译，输出到独立 build 目录，运行后在该目录写 `projectile-playback-result.json` 并退出。本子代理未编译或运行 AIR/JVM。

覆盖普通弹中段、闪电/火焰/激光、原生帧保持、结束边界、禁止外推、翻转、同批短弹迟到及先处理新弹、重复包不重启、暂停、射手时钟缺失、已显示弹不重播、无视觉探针不造视觉。实际玩家/敌人弹道、暂停/死亡与单次爆炸显示仍需母会话统一实机验证。

迟到补播本质上保住已丢失的画面，不消除网络延迟；长期帧率低或持续严重积压仍需解决根本负担，不能把本候选描述为整侧性能修复。
