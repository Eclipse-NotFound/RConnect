# A22 最小修复覆盖层

这里保留针对实际安装 A22 的源文件改动，不把未发布的 M51 或 B 架构混入候选。

`tools/validation/prepare_a22_fixes.py` 先逐文件验证 `build/m52/a22-map-only-02` 的精确 A22 加地图修复源，再用本目录 `src` 中的同路径文件覆盖；编译源、测试源、依赖、产物和覆盖前后哈希一起冻结在新的 `build/m52` 目录。没有 `--overrides` 时只生成诊断基线。安装目录不改。

新增修复均需先用实际 A22 原始字节负对照，再测试候选；源码线索与实测结论记录于 `state/a22-followup-2026-10-15.md`。

注意：上述源基线携带的游戏本体仍是旧安装副本。安装本体已更新时，不能直接部署该 native。`tools/validation/prepare_a22_native_rebase.py` 接受冻结父候选和明确的当前本体 SHA，只在新目录把已审 Land 修正合入当前本体，保留父模组字节；Land 原稿不一致时中止，不覆盖其他开发者更新。完成后仍须用匹配的新运行组合测试。

仅调整测试时使用 `tools/validation/prepare_a22_testpack.py`，保持生产源码、版本和模组字节不变，冻结测试及父候选的编译声明依赖。所有准备入口拒绝覆盖旧候选；失败记录保持原状。
