# 有限速度偿还校准债务

仅候选源，未在本目录运行 JVM、AIR 或部署。完整产品基底为已安装 `78C052AE / 0.2.24-roomfix5`；仅 `RemoteMotion` 和版本号改变，其余79类不变。保留 `89F1B923 / motionclock1` 的区间切线冻结。既有配方和失败证据不修改。

v1 把每个较小的时钟改善从显示时刻的直接跳转改为普通 1.1 倍速追赶，却未记录它们的累计值。32次50毫秒可以累计为1600毫秒，不能因每一笔都小就当作普通抖动。实际原生跳跃也观察到加入侧重播旧动作；录制前的包、offset 和 cursor 没有记录，不能声称恢复了完整故障输入。

本候选只增加一个 `calibrationDebt` 数值。收到更及时的普通包时累计债务，包回调不推动显示时钟；只有新的 `sample()` 时间才偿还，最多额外推进这一帧已经过去的时间，即校准期间总速率不超过2倍。达到当前缓冲目标或最后收到的位置就停止。无债务的普通±10%及敌人平滑追赶分支保持原样；立即显示的掉落物策略保持原样。暂停收口、转回旧式无时间戳插值、原有连续性重置会清除旧债务。

有限时长特效持有 `retainRate` 时，仍严格按1倍播放；债务暂存，最后一个持有者释放后才追赶。这意味着1600毫秒历史积压不能在一帧内无跳变地消失：在2倍上限下约需额外1600毫秒的真实时间，加上缓冲目标改变的普通调整。连续校准若以每50毫秒改善50毫秒的速度到达，可以在到达期间逐笔消化；若校准到达速度持续超过可偿还速度，无法同时承诺即时追平与2倍上限。本候选不隐藏这个限制。

原有断流超过1000毫秒、时钟一次突变超过原250毫秒门槛（大 interval 仍沿原公式）、距离超过600像素等连续性重置仍保留，允许清空旧轨迹；这些明确重置不属于普通包校准的同刻不动保证。公开的 `settle()` 本来就用于暂停时对齐最后位置，也不是普通平滑采样。单次200毫秒校准额外覆盖在新组件内，不能借旧 v1 的100毫秒分界直接 seek。

## 检查与边界

原37项组件正文、阈值和辅助存根全部保持，入口只追加31项，总68项：

- 普通玩家、念力对象、敌人各跑32次50毫秒的累计改善；同刻推包、重复采样不移位；每10毫秒源时钟最多推进20毫秒，恒速线段最多移动1像素；不超过已接收端点；最后一次校准后50毫秒内恢复当时125/100毫秒的目标缓冲。
- 两个特效持有者期间保持1倍；释放一个无效；释放最后一个后仅按真实采样时间、最多2倍追赶；2000毫秒内恢复缓冲。检查重复/倒序包、暂停收口、闲置重置及单次200毫秒校准。
- 从 `74932502cf` 和 `99eea9cf09` 的加入侧原始记录各截取首3000毫秒，精确保留74/79条输入和55/56个 RENDER 观测。以首个已知包重新初始化，渲染事件时刻作为明确的回放时钟，**不等同原 `presentationTime()`，不伪造录制前队列，也不要求复现原始像素轨迹**。用实际节奏检查同刻变化、单调时钟、2倍上限、收到的范围及末尾缓冲。入口会核原始测量文件 SHA 与数组逐项一致。

这些行为检查不是性能测试，不能授予玩家、念力、密集战斗或本机跳跃流畅资格。尤其2倍追赶会暂时加快远端动作，应在同一原生驱动中复测启动、跳跃、念力、暂停和有限特效，不能只看组件 PASS。
