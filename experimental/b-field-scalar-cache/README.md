## 改动与依据

本轮真实双实例诊断 `build/ab/b-dense-profile01`，8/80敌人各45秒。主侧80敌人采集24.40ms/次，内部字段11.56ms、身体8.42ms、血条1.87ms、原生动画帧1.65ms；加入单位应用12.97ms/次，字段5.56ms。区间互不重叠，保留外层与剩余差额，详见相邻目录 `b-field-dense-profile/profile01-analysis.json`。该诊断有额外计时，不能与净性能帧率直接比较。

候选只改两类内部实现和版本号：

- 原生字段名和类型分类使用固定元素类型的数组，并把本次遍历长度移出循环。字段集合、顺序、取值、无效值排除及差异编码均不变。
- 位图是没有子节点、文字或时间线的叶子。无滤镜且不导出像素时，直接比较它的完整固定配方，减少临时对象和通用属性遍历；其它情况走原路径。颜色、矩阵、透明度、可见性、混合、采样设置仍逐次读取。显示实例的类名用弱引用缓存，实例换掉就使用新键。

没有降低采集频率、删除动画、改伤害、改物理或改播放缓冲。`candidate02.patch` 为相对准确field22的完整源码差异。
