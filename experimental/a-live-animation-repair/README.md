## 当前实现

- 发出玩家快照时，用原生 `diag_up/diag_down && dx==0` 明确停止姿态，纠正 AIR 残留的 isPlaying=true，不凭远端位移猜动作。
- 活门窗破坏保留 `die(-1)` 的单次状态改变，再按原生材质播放碎片与声音；不调用损伤/任务/奖励脚本。历史房间恢复静默，重复 dead 消息无效。
- 死亡交接移除旧运动时钟引用，死亡/死亡姿态改变随快速状态发送，原生显示逐帧推进，镜像不执行 Unit.die。
- 高频状态仅发送弹道新增帧及重叠锚点，接收端按源时间合并；原完整状态保留新发现单位的回补。普通子弹也使用实际显示帧，避免用旧端点事后补演飞行。
- 开火播放期限按原期限累加，避免每次从“当前时间”重设造成逐发量化延迟；长中断重置界限保留。
