整理覆盖包不会改变代码本身的行为；具体累计改动以 `changes.patch` 为准。补丁用于审阅，需要完整源码时使用组装脚本。

## 只组装源码

在 `mods/RConnect` 下使用已配置的 Python 运行：

```text
python experimental/b-field-visual-motion-final/prepare.py --output build/ab/b190-visual-motion-final-check03-source
```

脚本先核验准确基线的构建清单与每份源码，再核验本目录差异文件、盖章模板和组装后的完整指纹。输出必须是 `build/ab` 下不存在的新目录，名称仍以 `b190-visual-motion` 开头、以 `-source` 结尾。脚本只复制源码并写入组装记录，不编译、不运行游戏、不部署，也不覆盖已有输出。存根仍需正式构建入口确认没有嵌入最终产物。
