# 安保终端权限候选

用户要求在紧凑浮窗的设置页选择「共享破解」或「分别破解」，由宿主管理、默认共享。切换不撤销已有权限，只影响以后取得的权限。个人终端尝试和失败次数不能被对方覆盖。

本目录仅保存独立新增类；入口、配置、HUD和GameBridge的接点由`tools/validation/prepare_security_terminals.py`在准确冻结A39上机械合并。禁止直接编译根src，禁止用此候选覆盖其它功能的活动源。

- `SecurityAccessState`：保存本次联机/地图各房间的原始授权，不因后来切换设置改写；重复消息幂等、收到的数据独立复制。
- `SecurityTerminals`：宿主管策略和收据，当前房间原有执行端负责原生AI/伤害；个人终端进度独立，离线走原生行为。
- 两个`fe`适配器：只读写必要原生字段，不另写炮塔AI或伤害公式。
- 配套本体副本仅接入Interact、UnitTurret、Bullet；高级破解改变阵营后，未授权玩家仍需正常被锁定/命中并能够反击。未获得安装授权或完整验证前不写游戏本体。

生产候选、配套副本、驱动和失败/未启动记录以[state/security-terminals-2026-10-19.md](../../state/security-terminals-2026-10-19.md)为准。准确10/native02已通过432项双侧原生检查、普通加载器冒烟及50项源码未变的组件检查，未部署。10另修复旧通用生成通道误建原生Area/Trap，保留原实例/脚本，新陷阱用原生构造并验证伤害。现有密集性能红项仍在，不把本功能通过称为整版稳定。不新增跨重启的随机探索战斗存档、稳定重连或其它版本兼容。
