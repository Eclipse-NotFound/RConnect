# 普通房 case3：相邻空碰撞格上的真实墙沿痕迹被丢弃

准确证据：`build/m52/recovery22-ordinary-wall-native-01` / run `215270505b`，recovery22 + ACC 宿主，同一普通房驱动。原框架双方 34/0；严格像素比较前三例通过、case3 失败，原结果不改。本目录只读分析，无源码修改、编译或运行。逐点颜色、全部变化时间及文件哈希见 `evidence.json`。

**已定位为漏传，不是颜色逆表仍有 1 级误差。** 加入侧等离子枪 8 发真实命中产生 1089 个变化像素，其中 22 个在主侧始终等于双方最初 baseline。它们集中在世界 `(1118..1119, 320..330)`，即 cell `(27,8)`；目标实墙是右侧 cell `(28,8)`，起点 x=1120。22 个像素中 10 个完全不透明、11 个 alpha=126、1 个 alpha=62，RGB 差异最高 130。源 nativeOracle 与最终 native 逐 uint 完全一致；主侧 native/display 同样缺这 22 个，其余 1067 个准确。分析器的 `native_wrong` 包括“仍为 baseline”的情况，不能仅据字段名把这次称为错色。

源端这些像素从第一/第二次命中后逐次变化，最终在墙钟 `1792647180452` 稳定。到源最后观测 `1792647188125` 已持续 7673ms 不变；主侧最后观测 `1792647188059` 仍完全缺失，距源最终变化 7607ms。因此不是把持续开火误计成传播延迟，也不是源结束后只等了一两帧。52 条加入侧收到的累计/快速墙痕元数据中没有 cell `(27,8)`；这些日志没有记录源 report/ACK 的原始颜色，故不拿它单独证明 ACK 内部状态。

确定调用链：

- 驱动 `LargeWallSurfaceTestDoc.choose:80–103` 使用自然地形，射线准入要求目标左侧 7 格、上下各 1 格的 `phis==0`。故本次 `(27,8)` 是真实空碰撞格，未由夹具造墙或手工涂色。其前景 bitmap 却已有非零 alpha 的墙沿，baseline 就能直接证明。
- 准确 ACC `Grafon.dyrka:4481` 的等离子路径调用 `decal`，`decal:4723,4754–4758` 在实际 frontBmp 上 erase/draw，并以原 bitmap alpha 通道保留可见轮廓；它不把着色硬裁到 40×40 的碰撞格。因此真实墙沿可以位于 `phis==0` 的相邻格。
- 准确22 `WallImpactVisuals.solid:141–145` 只判断 `phis>=1`。`observe:240–242` 遇 `(27,8)` 会 `discard`，把已变色 bitmap 复制进 shadow，然后跳过 `captureCell`。本次22个实际变化因而不会加入 queued/cells。后续 `put:407`、`settle:460`、`updates:482`、`snapshot:513`、`checkpoint:531`、`replay:550` 也有同一物理格过滤。仅改采集一处仍会在传输/接收/回放链丢掉。
- `put:427` 与 `replay:554` 的 `NativeWallColor.setter` 已在准确22，且本例主侧根本没写过这22个点；逆色表不是这一失败的原因。没有证据表明预测/ACK 把它们写过又回滚，完整主侧 RENDER 序列始终是 baseline。

最小修正方向是**让普通房“确有原生前景的像素”参与痕迹保存，而不是要求其所在碰撞格必须为实墙**。继续保留现有稀疏 cell、版本、ACK、尺寸/字节上限和颜色逆表；不需要改武器或随机渲染。不能简单把所有 `solid` 判断删掉：这些判断同时承担毁墙后不复活旧图像的责任。实现前应以完整真实 `WallImpactVisuals` 做一个窄反例：phis=0 的相邻格中有实际 alpha 前景，真实接触范围内发生颜色变化，旧类 report/settle/replay 丢失、新类全链保持；随后销毁支持该边缘的实墙、使 native 前景归零，旧排队包和重访 replay 均不得恢复它。候选可用现有 native 前景像素的可见支持作为非实墙格的逐像素准入，毁墙/重建仍由实际前景重建清除；非当前房间的 checkpoint/回放也必须保存这一边界，不能因 b==null 草率丢掉或无条件放行。

上述是有限修正责任与必须保留的反例，尚未证明某个实现安全；本次不新增协议或长期历史，也不宣称无需组件即可部署。下一次原生只需同字节普通房驱动验证这条缺口及既有毁墙回归，严格 uint 比较不变，不靠重复运行碰运气。
