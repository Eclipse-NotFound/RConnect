本复核按每个游戏帧的第一条可见RENDER计算窗口，得到110ms；原验收按最后一条可见RENDER得到109ms。保留原109ms判据，不拿不同采样口径替换验收。其它大窗口也只作关联证据。所有输入SHA及每轮失败项保存在review.json。
