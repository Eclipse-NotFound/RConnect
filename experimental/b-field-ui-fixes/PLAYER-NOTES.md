# B 本轮候选：玩法与操作说明

2026-10-25。供主会话编写发布说明；以其最终验证、部署结果为准。

| 玩家会看到的变化 | 怎么使用 |
|---|---|
| 主侧换房后保留自己选择的缩放，包括重新回到旧房间。 | 自动生效，继续使用原游戏缩放操作。 |
| 加入侧开锁、破解时能看到原生进度条；取消或完成后消失。 | 照常按住交互键操作。 |
| 加入侧 NPC 头顶对白和伤害数字减少额外的左右跳动。 | 自动生效，数字的原有上浮、淡出动画仍保留。 |
| 加入侧的 Q 瞬移按自己看到的亮区判断，不再借用主侧的视野。 | 照常蓄力、选择有效位置并释放；墙体、法力等原有限制仍适用。 |
| 可以用念力接住队友投出的普通手雷、酸性炸弹，再把它投回。 | 用默认 Q 瞄准抓取，默认 E 投出。引信继续计时，握在手里也会到期。 |
| 安保终端可选择共享破解或分别破解。 | 主侧在浮窗“设置”页向下滚动，点击“安保终端”。 |

**安保终端的两种方式：**“共享破解”让一人完成后双方获得对应权限；“分别破解”要求各自完成。中途切换影响之后的破解，已经获得的炮塔安全权限保留。加入侧可查看当前方式，由主侧设置。

**相关的现有开关：**

- “队友”页的“跟随队友”各自设置；关闭后可以在同一地图的普通房间分头行动。“允许队友伤害”由主侧设置。
- “设置”页的“允许队友念力抓起我”和“被抓时 WASD 挣脱”各自设置；它们控制玩家自身被抓，不是抓取飞行手雷的开关。
- “允许队友抛掷伤害我”只控制被队友抛出后的撞击伤害。菜单、SATS 的共同暂停也在“设置”页，由主侧设置。
- F10 隐藏或恢复浮窗；当前页可用滚轮向下翻。窗口不透明度在“设置”页顶部。
