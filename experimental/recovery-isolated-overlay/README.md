# 准确基底的小范围隔离覆盖

为本轮两项诊断复用原构建入口，避免复制一套专用编排。仅接受已存在的 C6A3 普通墙面产品或 EB365 安装版来源，覆盖至多六个既有 AS 类并修改版本；输出限定新建 `build/m52/recovery-*-NN`。不写 release、游戏宿主或真实存档。

原产品的源码、构建输入、产物及历史回执均核对；实际22项安装只允许历史记录中的 RConnect 精确变成 EB365，其余21项须相同。原 `build_mod.py` 在隔离目录执行，监督其两次 JVM；共享登记、1 GiB 编译前置、512 MiB 运行保护及自有进程回收沿用现有工具。输入及安装在编译后再核，失败不覆盖。

`--diagnostic` 明确标记诊断产物。编译成功只表示可进入后续测试，不是玩法、性能或发布资格。逐行 diff 只将显示用的换行统一，源码原始字节与指纹仍单独保留。
