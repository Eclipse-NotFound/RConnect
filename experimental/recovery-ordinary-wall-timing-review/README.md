## 下一处最小可验证改动

可以单独候选化：**仅当有效墙面 ACK 真正退役 pending 后，立即尝试发送一次已排队的墙面批次**，保留同房/epoch/term、ready、非权威、连接就绪条件和单一 pending；不重复触发地雷、伤害、容器及全场景扫描。无效或重复 ACK 不触发发送；没有 queued 不发空包。宜令真实墙面 acknowledge 返回“此次确实退役”的布尔结果，而不是靠收到任何 ACK 推测。

这只消除代码上确定存在的“上一批已确认却仍等下次 Timer”的机会延迟；**现有证据未证明本轮每次都在等待 ACK，也不能承诺它改善第一发 129 ms**。验证应保留当前全部像素/生命周期断言，另核有效 ACK 后下一批只发一次、旧 ACK 不消费新批次，以及用相同逐阶段完整像素匹配观察后续延迟；不先移除单飞行屏障或提高全同步频率。不据此给出性能通过资格。
